# SAC ICAO Contact Directory & Email Generator

## Project Overview

The **ICAO Contact Directory & Email Generator** is an educational web-based tool designed to streamline communication with the International Civil Aviation Organization (ICAO), its Regional Offices, and Member State Civil Aviation Authorities. Developed for aviation students and professionals, this application provides a centralized repository of official contact information and automated formatting for diplomatic communications.

### Purpose

This tool addresses a common challenge in aviation governance and policy: locating current, accurate contact information for ICAO representatives, Secretariat departments, and regional aviation authorities. By aggregating official contact data and standardizing email formatting according to diplomatic protocols, the directory reduces communication friction and promotes efficient engagement with international aviation governance structures.

---

## Key Capabilities

### 1. **Mission & Delegation Email Generator**
- **Live Search Functionality:** Quickly locate known ICAO representatives by name across all Member States
- **Member State Dropdown Selection:** Browse and select from the complete roster of ICAO Member States
- **Auto-Populated Fields:** First and last names auto-fill when representatives are found in the cached registry
- **Diplomatic Format Standardization:** Automatically formats email addresses according to official UN standards (e.g., `firstname.lastname@[country]un.int`)
- **Primary & Secondary Routing Options:** Displays multiple valid routing formats for each representative
- **Copy-to-Clipboard:** One-click address copying for immediate use in email clients

### 2. **Routing Format Registry**
- **Member State Lookup:** Query established routing patterns for Civil Aviation Authorities (CAA) and Ministries of Foreign Affairs (MFA)
- **Format Verification:** Verify current addressing standards before initiating correspondence
- **Authority Differentiation:** Distinguishes between diplomatic channels (UN Mission delegates) and technical/administrative channels (CAAs)

### 3. **Secretariat & Internal Email Generator**
- **Organizational Branch Selection:** Choose from four ICAO organizational categories:
  - Headquarters (General)
  - Regional Offices
  - Bureaus & Departments
  - Executive Leadership
- **Automatic Address Generation:** Produces official internal routing addresses (e.g., `department@icao.int`, regional office addresses)
- **Multi-Format Output:** Displays mailing addresses, phone numbers, fax, and direct email contacts
